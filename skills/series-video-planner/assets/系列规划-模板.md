
### 5.2 声音链（顺序不可颠倒）

```
无声母版.mp4 + 字幕.srt
   ├─ ① 先合配音 → 配音总长 > 画面总长时，按对齐报告拉长整幕
   └─ ② BGM 最后合，用「配音版母版」的最终时长算卡点
```

**为什么 BGM 必须最后合**：配音对齐会改变整片时长（实测 172.0s → 198.9s，逐幕放大 1.07–1.28 倍）。先合 BGM = 把拍点算在一个已作废的时间轴上。

### 5.3 Voice-ready 字幕规范（硬性）

| 规则 | 值 |
|---|---|
| 朗读语速基准 | **5.0 字/秒**（区间 4.6–5.5） |
| 单条字幕字数 | **12–24 字**，硬上限 28 |
| 单条槽位时长 | **2.6–4.5s**，按 `字数 ÷ 5.0` 估算 |
| 幕边界 | **必须落在字幕边界上** |
| SRT 格式 | UTF-8 无 BOM、条间一个空行、编号从 1 连续 |
