# series-video-planner

把大主题（万字长文 / 大专题 / 大部头书籍）拆成 N 集系列视频并做成合集的规划方法论 skill。

单集生产不在本 skill 范围 —— 拆完之后每集交给 [handdrawn-explainer-video](../handdrawn-explainer-video/) 或 [dark-field-explainer-video](../dark-field-explainer-video/) 制作，封面交给 [douyin-cover-generator](../douyin-cover-generator/)（系列自建风格时以风格总纲为准）。本 skill 管的是「集以上」的所有决策与协作模式。

## 核心内容

- **风格总纲前置（v2 新增）**：画风 / 视频风格 / 封面风格**必须在拆分之前**一次定死，产出 `系列风格总纲.md`（人读）+ `style-tokens.json`（机器读，工程与封面脚本共用），全系列继承、各集不得自创
- **从主旨推导风格的三步法**：主旨拆 3 句 → 每句强制翻译成视觉决策 → 反推红线。附样张验证（正片帧 + 竖横封面 + 1/4 缩图）
- **资料分级扩展（v2 新增）**：A 级足够则不扩展（明确写"不扩展"）、B 级定点补 1-2 处、C 级（含量不足或**结论会过期**）必须扩展并标注更新时间
- **拆分逻辑四原则**：不按章节机械切 → 按认知弧重组 → 每集一个可独立成立的心智模型 → 番外机制；**书籍类特例**：作者已排好认知弧的书，忠于章节边界
- **讲透 vs 导读的取舍**：按 0.06~0.08 s/字算清"讲透要多少集"，再决定做改编还是做指南
- **链接强度三档光谱**：完全独立 / **模块化系列（默认推荐）** / 强连载；三件链接器 = 共享主图点亮层 + 回指一句话 + 片尾预告与菜单
- **Voice-ready 字幕（v2 新增）**：按 5.0 字/秒、单条 12-24 字、槽位 2.6-4.5s、幕边界落在字幕边界上；**声画链顺序为 无声母版 → 配音 → BGM**（配音会改变时长，先合 BGM 等于把拍点算在作废的时间轴上）
- **双线制作模式**：主线负责调研与独立验收，SubAgent 封闭在单集文件夹里并行制作（一次 2 集）

## 结构

```
series-video-planner/
├── SKILL.md                              # 6 步工作流完整手册
├── references/
│   ├── case-study-linux-memory.md        # 技术长文类案例（Linux 内存管理 7 集系列全记录）
│   └── case-study-book-guide.md          # 书籍类案例（《以日为鉴》17 集阅读指南）
└── assets/
    ├── 系列规划-模板.md                     # 系列规划文档模板（含资料分级与 voice-ready 规范）
    ├── 系列风格总纲-模板.md                  # 风格总纲模板（10 问 + 八条铁律 + 封面策略 + DoD）
    └── style-tokens-模板.json              # 机器可读风格令牌模板
```
