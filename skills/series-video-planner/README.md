# series-video-planner

把大主题（万字长文 / 大专题 / 大部头书籍）拆成 N 集系列视频并做成合集的规划方法论 skill。

单集生产不在本 skill 范围 —— 拆完之后每集交给 [handdrawn-explainer-video](../handdrawn-explainer-video/) 或 [dark-field-explainer-video](../dark-field-explainer-video/) 制作，封面交给 [douyin-cover-generator](../douyin-cover-generator/)（系列自建风格时以风格总纲为准）。本 skill 管的是「集以上」的所有决策与协作模式。

## 核心内容

- **每份产物回答一个问题（v2.3）**：文档不是越多越好。每份必须有"别处答不了的一个问题"，否则合并或删掉。见 `references/doc-set.md`
- **只做总览也是完整交付**：做完规划 + 风格 + **1 个样板集**，其余集交给别人按样板做
- **风格引擎三层结构**：`style-tokens.json` → `archive.js` → `scenes.js`。字幕坐标、色值、动效全部封进组件，**场景文件里根本写不出来**——风格一致性靠 API 强制，不靠纪律
- **导师模式**：派单任务书六要素 + 四道验收闸门 + 常见偏离打回清单
- **风格总纲前置**：画风 / 视频风格 / 封面风格必须在拆分之前一次定死，产出 `系列风格总纲.md`（人读）+ `style-tokens.json`（机器读）
- **从主旨推导风格的三步法**：主旨拆 3 句 → 每句强制翻译成视觉决策 → 反推红线。附样张验证
- **资料分级扩展**：A 级足够则不扩展（明确写"不扩展"）、B 级定点补 1-2 处、C 级（含量不足或**结论会过期**）必须扩展并标注更新时间
- **拆分逻辑四原则** + **书籍类特例**（作者已排好认知弧的书，忠于章节边界）
- **讲透 vs 导读的取舍**：按 0.06~0.08 s/字算清"讲透要多少集"，再决定做改编还是做指南
- **呈现原则**：文字直接给、物件才做动效；并列整组给、对抗错开、递进逐条
- **Voice-ready 字幕**：5.0 字/秒、单条 12-24 字、槽位 2.6-4.5s、幕边界落字幕边界；声画链 = 无声母版 → 配音 → BGM

## 每份产物回答什么问题（v2.3 核心）

> 判据：**这份文档有没有一句话是别处答不了的？** 没有就合并或删掉。
> 实际检验：Ep00 曾同时维护 3 份文档，其中 **30/34 条字幕被原样抄了两遍**，动效白名单抄了两遍，时间码抄了 4 遍。

| 产物 | 唯一职责 | 不写什么 | 真源在哪 |
|---|---|---|---|
| `调研材料.md` | **数据从哪来** | 不写字幕、不写时间码 | 硬数字表、口径、勘误红线 |
| `视频分镜脚本.md` | **每幕承重什么**（意图层） | **不抄字幕全文**（只写条号）、**不写"为什么"**、不重复风格规则 | 时间码 → `SCENES` 数组 |
| `运镜与制作思路.md` | **为什么 + 踩过什么坑** | 不重复风格规则、不重复呈现原则、不重复分镜表 | 风格规则 → `系列风格总纲.md` |
| `字幕.srt` | **说什么 + 何时说** | — | 字幕唯一真源 |
| `发布文案.md` | **发出去时标题/正文/话题怎么写** | 字幕全文、画面描述 | 机读 JSON 块 |
| `系列风格总纲.md` | 画风/视频/封面的**通用规则** | 不写单集内容 | 规则唯一真源 |

**本集特有 vs 全系列通用**：只有"这一集为什么这么设计"该留在集目录；凡是能写进 `系列风格总纲.md` 的（呈现原则、动效白名单、版式、布光）一律上提，集目录里只留指针。

## 结构

```
series-video-planner/
├── SKILL.md                              # 8 步工作流完整手册
├── references/
│   ├── doc-set.md                        # 每份产物回答什么、该删什么、模板
│   ├── presentation-rules.md             # 呈现原则（文字直接给 / 并列整组给 / 什么才做动效）
│   ├── style-engine.md                   # 风格引擎三层结构（怎么用代码强制画风一致）
│   ├── mentor-guide.md                   # 导师手册（派单六要素 + 四道闸门 + 打回清单）
│   ├── case-study-linux-memory.md        # 技术长文类案例（Linux 内存管理 7 集）
│   └── case-study-book-guide.md          # 书籍类案例（《以日为鉴》17 集阅读指南）
└── assets/
    ├── 系列规划-模板.md                     # 规划文档模板（含分级与 voice-ready 规范）
    ├── 系列风格总纲-模板.md                  # 风格总纲模板（10 问 + 八条铁律 + 封面策略）
    ├── style-tokens-模板.json              # 机器可读风格令牌模板
    └── 集目录模板.md                        # 完整集目录样板（文件清单/组件速查/命令序列）
```
